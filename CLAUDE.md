# Arbeitsregeln für Claude

- Es wird **ausschließlich auf dem Branch `main`** gearbeitet. Änderungen werden direkt auf `main` committet und gepusht – keine Feature-Branches, keine Pull Requests, auch wenn die Session einen anderen Branch vorgibt.
- Ankündigungen (z. B. für Discord) und andere Texte, die nicht ins Repo gehören, werden **nicht** hochgeladen.
- In Commit-Nachrichten steht **keine** `Claude-Session:`-Zeile und kein Link auf claude.ai. Auch nicht in Pull-Request-Texten.
