Credentials

  • DD-Installer does not store credentials on your computer: SSH passwords, key passphrases and the Funcom token are held in memory for the running session only and are never written to disk, logs or configuration files by this tool, and never sent to anyone but the server you chose.
  • Neither RedBlink nor Prophet (author of DD-Installer) receives, collects or stores your credentials.
  • Be aware that the installed Dune Docker software itself stores the Funcom token and the generated admin password in files on your server (runtime/secrets/). That is upstream behaviour you control.
  • If you let the assistant enable temporary passwordless sudo, it is removed again at the end of the run; if the installer is killed earlier, remove /etc/sudoers.d/90-dd-installer manually.
